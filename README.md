# CAD.remeslo

CAD-моделирование для планшета (Android). Three.js + OpenCascade (через replicad, WebAssembly).

## Запуск

```
npm install
npm run dev
```

Откройте адрес из строки `Network:` (например `http://192.168.1.10:5173`) на планшете в той же Wi-Fi сети.
Если Windows спросит про брандмауэр — разрешите доступ для частных сетей.

## Сборка APK (Android)

```
npm run apk
```

Результат: `android/app/build/outputs/apk/debug/app-debug.apk`.
Нужны Android SDK (`android/local.properties` → `sdk.dir`, или переменная `ANDROID_HOME`) и JDK 21:
путь берётся из `JAVA21_HOME`, иначе `~/Android/jdk-21` (Gradle 8.14 не работает на JDK 25).

В APK экспорт STL/STEP/проекта сохраняется в «Документы/TabCAD».

## Структура

- `src/kernel.ts` — CAD-ядро: примитивы, булевы операции, скругления, сетка, экспорт STL/STEP
- `src/doc.ts` — документ (список тел) и история undo/redo
- `src/viewport.ts` — 3D-окно, жесты, выбор касанием, манипулятор
- `src/sketch.ts` — 2D-геометрия эскизов и плоскостей
- `src/constraints.ts` — связи и размеры эскиза, решатель
- `src/regions.ts` — авто-области: разбиение эскиза пересечениями на замкнутые области
- `src/recognize.ts` — распознавание фигур, нарисованных от руки
- `src/storage.ts` — хранилище проектов (IndexedDB)
- `src/project.ts` — формат файла `.tabcad`
- `src/main.ts` — интерфейс и команды

## Готово (этап 0–1)

- Куб, цилиндр, сфера с редактируемыми размерами
- Объединение, вычитание, пересечение
- Скругление и фаска всех рёбер тела
- Перемещение манипулятором и вводом координат
- Отмена/повтор, копия, удаление
- Экспорт STL и STEP

## Готово (этап 2)

- Эскизы на плоскостях XY/XZ/YZ и на любой плоской грани тела
- Линия (многоугольник), прямоугольник, окружность; привязка к сетке и к точкам
- Редактирование размеров профилей числами
- Вытягивание стрелкой или вводом расстояния, с предпросмотром
- Режим «Авто»: на грани тела «+» добавляет материал, «−» вырезает

## Готово (этап 3)

- Режимы выбора: тело / грань / ребро (клавиши B / F / E)
- Скругление и фаска выбранных рёбер
- «Тяни-толкай» плоской грани стрелкой (касательные скругления сдвигаются вместе с гранью)
- Оболочка (полое тело) с открытыми выбранными гранями
- Эскиз на выбранной грани

## Готово (этап 4)

- Автосохранение проекта (IndexedDB) через секунду после изменения и при сворачивании
- Экран проектов: миниатюры, открытие, новый, переименование, копия, удаление
- Файл проекта `.tabcad` (JSON + точная геометрия BREP): скачать / открыть
- Импорт STEP и STL в текущий проект
- При запуске открывается последний проект

## Готово (этап 5, v0.5.0)

- Размеры в эскизе (ширина/высота, диаметр, длины отрезков); касание размера — ввод значения
- Подсветка граней/рёбер под курсором или пером; при выборе плоскости эскиза — только плоские грани
- Перспективная / ортогональная проекция
- Кубик вида: 6 стандартных видов + изометрия
- Неоморфное оформление, светлая и тёмная тема
- Включение/выключение привязки к сетке (кнопка ▦ или клавиша G)
- В эскизе скрывается общая сетка — больше нет «двойной» сетки

## Готово (этап 6, v0.6.0)

- Приложение называлось remeslo.cad (с v0.12.0 — CAD.remeslo); файл проекта — `.remeslo` (старые `.tabcad` открываются)
- Эскиз: прямоугольник из центра, эллипс, паз (осевая линия + ширина)
- Инструмент «Точки»: перетаскивание и удаление точек, скругление углов (одного или всех)
- Размеры от точки эскиза до рёбер тела в плоскости эскиза и до осей эскиза; касание размера сдвигает фигуру
- Скругление/фаска рёбер стрелкой на ребре с живым предпросмотром
- Манипулятор масштаба: по осям (куб, высота цилиндра) и общий
- Массивы по прямой и по кругу (отдельные тела или одно)
- Подписи размеров больше не «прыгают» при движении курсора

## Готово (этап 7, v0.7.0)

- Кнопка «⋯» у каждого тела: копировать, скрыть/показать, заблокировать/разблокировать, удалить
- Заблокированные тела не выбираются в 3D-окне и не меняются (но их грани годятся под эскиз)
- Мультивыбор: «Рамка» (выделение прямоугольником), «Все» (Ctrl+A), групповые действия
- Симметричное вытягивание — поровну в обе стороны от плоскости эскиза
- Связи в эскизе: параллельность, на одной прямой, касание, совпадение точек, точка на линии
  (свой итеративный решатель в `src/constraints.ts`; связи сохраняются и держатся при перетаскивании)
- Вспомогательные плоскости: смещение (со стрелкой), под углом через ось (оси плоскости или ребро тела),
  по трём вершинам тел

## Готово (этап 8, v0.8.0)

- Тела вращения: инструмент «Ось» в эскизе, переключатель «Вытягивание / Вращение», угол, проверка пересечения оси с профилем
- Массивы вокруг выбранной оси: прямое или круглое ребро, цилиндр, ось эскиза; массив по прямой вдоль ребра
- Эскиз: ортогональный режим (кнопка «Орто» или клавиша O), незамкнутые линии сохраняются при смене инструмента
- Привязки: концы, середины отрезков, центры и квадранты окружностей, вершины/середины/рёбра тела в плоскости эскиза,
  «на линии»; тип привязки — в строке состояния
- Подсветка элемента эскиза под курсором/пером и тела под курсором в 3D
- Связь «перпендикулярно»
- Эскиз внутри тела виден насквозь (тела в эскизе полупрозрачные)
- Оси X/Y/Z на кубике вида; переименование тел и эскизов через «⋯»
- Производительность: точность сетки зависит от размера тела, кэш запросов к ядру (нормали, оси рёбер),
  тяжёлый предпросмотр (скругление, вращение) пересчитывается не чаще ~11 раз/с
- Предупреждения о пределах ядра: медленные операции (> 2 с), слишком детальные тела (> 400 тыс. треугольников),
  ось вращения через профиль, оси только у прямых и круговых рёбер

## Удобство на планшете (v0.9.0, пакет A)

- Перо и пальцы разделены: перо рисует и выбирает; касания пальцем рядом с работающим пером (ладонь) игнорируются;
  если перо использовалось, в эскизе палец двигает вид, а не рисует
- Касание двумя пальцами — отменить, тремя — повторить
- Вращение вокруг точки модели под пальцем, масштаб — к точке под курсором/пальцами
- Контекстная панель рядом с выделением (тело, несколько тел, грань, рёбра, профиль, плоскость)
- Своя цифровая клавиатура с выражениями и единицами (`40+5`, `100/3`, `4см`) вместо системной
- Свои диалоги переименования и удаления вместо системных
- Вибрация при привязке и создании элемента эскиза (`@capacitor/haptics`)
- В APK скрыты системные панели Android (полноэкранный режим), в браузере — «⚙ → Полный экран»
- «⚙ → Режим для левши» (инструменты справа), «▤» — свернуть панель свойств

## Меньше режимов, больше прямого действия (v0.10.0, пакет Б)

- Выбор «Авто» (по умолчанию): касание — грань, у самого ребра — ребро, двойное касание — тело целиком;
  фильтры «Тело / Грань / Ребро» остались (клавиши A / B / F / E); в контекстной панели грани/ребра — «Тело»
- Значения прямо на холсте: у стрелок вытягивания, тяни-толкай, скругления и смещения плоскости — подпись
  с числом, касание — ввод числа или выражения; при перетаскивании манипулятора — смещение или масштаб
- Компактная панель инструментов: группы Эскиз / Тела / Булевы / Правка / Файл, «›» или удержание — все
  инструменты группы; последний использованный становится кнопкой группы
- Удержание пера на плоской грани (или на профиле/плоскости) — эскиз на ней
- Подсказки при первом запуске («⚙ → Подсказки» — снова), пустой проект — крупные кнопки «Эскиз», «Куб»…

## Эскиз как на бумаге (v0.11.0, пакет C)

- Авто-области: пересекающиеся контуры и линии делят эскиз на области; касание выбирает область,
  следующие касания добавляют/убирают соседние; выбранные области вытягиваются одним телом.
  Граница области собирается из точных отрезков и дуг (окружности, скругления, пазы, эллипсы) —
  без граней-«ступенек». Контур, ни с чем не пересекающийся, выбирается как раньше, целиком
- Авто-связи при рисовании (кнопка «⚡ Авто-связи», включены по умолчанию): почти горизонтальный,
  вертикальный, параллельный или перпендикулярный отрезок выравнивается сам (значок у отрезка
  и подсказка в строке состояния); точки, привязанные к точкам или линиям других фигур, связываются с ними.
  Новые связи «Горизонтально» и «Вертикально» есть и в инструменте «Связи»
- Инструмент «✍ От руки»: штрих распознаётся как линия, ломаная, окружность, эллипс, прямоугольник,
  треугольник или многоугольник; концы прилипают к точкам эскиза, размеры — к шагу сетки
- Шкала истории (🕘 или клавиша H): все шаги с подписями («Вытягивание: + «Тело 5»»); касание шага —
  вернуться к нему, отменённые шаги можно вернуть, пока не сделано новое действие.
  Это история отмены, а не параметрическое дерево: изменить старый шаг и пересчитать последующие нельзя

## Белый экран вместо модели (исправлено в v0.12.1)

Отрисовка не освобождала видеопамять: каждая перерисовка черновика эскиза (при каждом движении пера),
предпросмотр операции и подсветка оставляли буферы на GPU — 400 движений пера давали 400 геометрий.
На планшете память заканчивалась, Android сбрасывал WebGL, и холст становился белым (подписи-HTML
оставались). Теперь всё убранное со сцены освобождается (`disposeTree` в `src/viewport.ts`), число
геометрий не растёт; если система всё же сбросит WebGL, сцена загружается заново автоматически.

## Связи и размеры (v0.12.0)

- Приложение называется **CAD.remeslo**, иконка — логотип (круг из четырёх секторов)
- Новые связи: «Равенство» (длины отрезков или радиусы окружностей) и «Закрепить» (точка не двигается;
  также кнопка «⚓ Закрепить» у выбранной точки)
- Начало координат и оси X/Y можно выбирать в связях: совпадение с началом, точка на оси,
  параллельность/перпендикулярность оси, касание оси
- Прямоугольник, который связь превращает в многоугольник, сохраняет прямые углы
  (стороны получают связи перпендикулярности)
- Размеры не наносятся сами: инструмент «Размер» — касание отрезка (длина) или окружности (диаметр),
  точка + ребро/ось — размер до ребра. Размер — это связь: перетаскивание точек его не меняет.
  Касание числа — изменить, пустое поле — удалить; список размеров с ✕ в панели
- «Шаг назад» в эскизе отменяет любое действие: фигуру, точку, связь, размер, перетаскивание, правку поля
- Клавиши цифровой клавиатуры видимо «утапливаются» при нажатии

## Своя сборка ядра (v0.8.1)

Стандартный `replicad-opencascadejs` не содержит `BRepBuilderAPI_GTransform`, поэтому неравномерное
масштабирование было недоступно. Ядро пересобирается через GitHub Actions
(`.github/workflows/occ-kernel.yml`): берётся та же версия replicad-opencascadejs (1.1.0) и к списку
привязок добавляются классы из `occ/extra-symbols.txt`. Готовые файлы лежат в `vendor/replicad-opencascadejs`
и подключены в `package.json` как `file:vendor/replicad-opencascadejs`.

Чтобы добавить ещё классы OpenCascade: впишите их в `occ/extra-symbols.txt`, запушьте — workflow соберёт
артефакт `replicad-single`; положите его файлы в `vendor/replicad-opencascadejs/dist`.

Теперь любое тело растягивается по осям. Кривые грани при этом становятся сплайнами (цилиндр — эллиптическим),
и последующие скругления/оболочка на таком теле работают медленнее — приложение предупреждает об этом.

Известное ограничение: оболочка не строится на частично скруглённых телах (ограничение OpenCascade).
